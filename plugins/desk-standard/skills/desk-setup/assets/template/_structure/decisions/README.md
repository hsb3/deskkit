# Decision spine

The desk's constitution. One file per decision, `NNNN-short-title.md` (zero-padded,
kebab-case), append-only, newest-first below. A decision that implies a code change graduates
to the owning repo's ADR + an issue, linked from the decision's `Affects` section.

Repair by what changed: the *decision* changed → supersession (new record, old marked
`superseded`); a *factual premise* was wrong → dated in-place correction. On a number
collision, renumber the later-filed doc and leave a dated redirect note at the old identity.
