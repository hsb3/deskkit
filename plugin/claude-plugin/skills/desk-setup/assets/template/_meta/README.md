# _meta/ — the working desk

The local working desk (five-layer skeleton: entry → **working desk** → decision spine →
workstreams → output shelves). Taxonomy:

- `HANDOFF.md` — the cold-start bridge; refreshed at every boundary. Intra-desk only.
- `improvement-log.md` — the desk's self-maintenance file: maintenance backlog, pass log, and
  the friction ledger the harvest loop reads.
- `secrets/` — the one never-committed home for secrets and live-ops. Never tracked.
- `briefings/`, `research/`, `plans/` — add these only when a live thread needs one (start flat).

Secrets live only in `secrets/` or in environment variables. Nothing here restates board
work-state — the board is the single truth.
